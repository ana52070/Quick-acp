# Quick-acp 0.1.8 更新说明

## 修复内容

修复TOOL-BUDGET-001：工具调用额度耗尽时，任务尚未完成却返回end_turn，导致客户端误标为完成。

- 保留默认12次工具调用额度，失败调用同样计数；可通过QUICK_ACP_MAX_TOOL_ROUNDS配置上限。
- 模型仍需调用工具但额度已耗尽时，返回ACP标准状态max_turn_requests，明确表示当前任务未完成。
- 同步推送并保存中文进度提示：已调用数、最后执行的工具与成功/失败状态、下一项尚未执行的工具及文件。
- 不执行超出额度的工具，不为其创建开始卡片，不重放已执行操作。
- 恰好用完额度后模型已能给出最终答案时，仍正常返回end_turn；正常答案不重复发送。
- 取消优先，包括额度通知异步发送期间收到取消的情况。进度提示仅展示工具名和文件目标，不回显命令、查询或提问正文。


Codeg自定义代理分发固定为quick-acp@0.1.8。多步骤工程可根据需要配置QUICK_ACP_MAX_TOOL_ROUNDS；额度耗尽时应根据提示继续处理剩余工作，不应把截断轮次视为任务已完成。
