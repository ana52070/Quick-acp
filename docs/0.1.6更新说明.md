# 更新日志

## 0.1.6

修复默认任务误选Quick云端设备工具后，本机任务无法推进的问题，并完善等待终止处理。

- 加强默认本机工具提示，文件与命令使用本地quick-tool-call通道。
- 检测原生设备工具调用后请求取消，将工具卡片收尾为失败；最多发送一次纠正提示，持续误用时返回协议错误。
- 网关单轮等待默认限制为180000毫秒，可通过QUICK_ACP_TURN_TIMEOUT_MS调整；取消立即唤醒本地等待。
- 发送失败后释放轮次状态；预先取消的任务不再发送；补齐上游工具结果与未完成卡片的状态收尾。

验证：19项原回归、9项路由专项、10步ACP Mock集成及类型检查通过，已有修复后真实网关复跑记录。Codeg重装0.1.6后的默认提示多轮复验通过：Quick使用本机工具完成待办CLI、23项测试、五步冒烟、验收文件写入与回读；调用记录未观察到云端设备工具。首轮认证中断及后续续验记录完整保留，详见[默认提示验收](0.1.6默认提示验收.md)。
